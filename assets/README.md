# Poppins

Regular (400), SemiBold (600), and Bold (700) TTFs are bundled from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/poppins).
The SIL Open Font License is included in `fonts/OFL.txt`.

Fonts work offline. After changing native assets, run `npx react-native-asset`
and rebuild the app. Fast Refresh alone cannot install font assets.
